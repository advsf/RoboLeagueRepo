# [RoboLeague]

A competitive multiplayer 5 on 5 football game with unique position-based abilities that enables players to control the field.

# Key Achievements
- Gathered a total of 25k downloads on Google Play and 7k on Steam.
- Promoted on various social media platforms, most notably Instagram, TikTok, and Youtube, resulting in a total of 2 million views.

# Key Details
- Implemented physics synchronization to handle the continuous Magnus Effect and downwards trajectory of the ball with client-side prediction (though Unity's indeterministic system makes it a little difficult to get it perfect).
- Developed a skill-based mechanic that allows players to control the strength of their curve depending on how fast they flick their mouse.
- Maintained server authority by writing custom server arbitration and reconciliation logic.
- Created two custom abilities for each position (CF, MF, and CB).
- Supports cross-platform gameplay between PC (Steam) and Mobile (Android).
- Handles a seamless 0-touch authentication for Steam and Google Play.
- Utilized Unity Cloud to handle leaderboards (total goals, saves, and assists), data recovery, player reports (sends a report to a Discord server), and account bans.

# Technical Aspects
- Used C# and Javascript to handle gameplay and cloud services.
- Used Unity's Netcode for Gameobjects to handle the lobby and multiplayer.
